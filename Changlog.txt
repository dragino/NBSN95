1. Network Information is displayed when accessing the network
2. Fix bugs where commands such as AT+UNAME display errors
3. The software automatically removes spaces to prevent customers from filling in the wrong address
4. Support TE UDP issuance, add command AT+DOWNTE.

8. Remove GE and 1D versions from the device name and unify them into one version, for example, S31-CB-GE becomes S31-CB
9. Add IMSI number in payload format
10. Change the GPS positioning search time from the default 30 seconds to 60 seconds
11. GPS debugging optimization, adding GPS on/off, fix timeouts, location information and other functions
12. Change the interrupt delivery logic of CB products
13. Increase the TDC interval for subsequent reconnection after network access failure
